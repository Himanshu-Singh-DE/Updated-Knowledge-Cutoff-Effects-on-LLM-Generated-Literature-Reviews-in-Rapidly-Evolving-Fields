# Data

All files are regenerated by `scripts/run_all.sh` from the pinned sources in `configs/lists.json`.

| File | Rows | Columns | Built by |
|---|---|---|---|
| documents.csv | 61,877 | paper_id, title, abstract, publication_date, date_precision, venue, year | src/build_corpus.py |
| list_matches.csv | 2,752 matched lines | list, file, section, paper_id, matched_title, n_ids_for_title | src/match_lists.py |
| queries.csv | 54 | query_id, query | src/build_labels.py |
| relevance.csv (+ _T2022-07-01, _T2024-07-01) | 2,305 | query_id, paper_id, relevance_grade (always 1), essential_post_cutoff | src/build_labels.py |
| query_meta.csv (+ variants) | 54 | query_id, query, group (source list), n_relevant, n_post, n_pre, active, split | src/build_labels.py |

* Dates are month precision (the first of the volume month). 698 papers with no month get YYYY-07-01 and `date_precision=year`.
* Leakage controls: labels are never read by `run_retrieval.py`. The split is by source list. The decay parameter is selected on tuning queries only (`select_h.py`).
* Query q17 does not exist: the two agent lists were merged into q16 before any run.
